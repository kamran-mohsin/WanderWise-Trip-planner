# 🌍 WanderWise - Trip Planner

A comprehensive full-stack web application designed to help users plan trips, manage travel itineraries, and handle payments seamlessly.

## ✨ Features
- **Trip Planning:** Organize and schedule your travel destinations easily.
- **Payment Integration:** Secure backend API to process and record trip payments.
- **Admin Dashboard:** Manage users, bookings, and notifications.
- **Responsive UI:** Clean, modern, and user-friendly interface.

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Backend:** Python, FastAPI
- **Database:** SQLite (`payments.db`)
